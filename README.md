## Descripción del proyecto

Este proyecto corresponde a la entrega de las katas de Python.  
El trabajo está realizado en formato **Jupyter Notebook** (`.ipynb`) para poder ejecutar cada ejercicio de forma individual y comprobar fácilmente el resultado.

En el notebook se incluyen los ejercicios con su enunciado y su correspondiente solución en Python.

## Archivo principal

El archivo principal del proyecto es:

```text
Carlos Parriego Urbano - CORREGIDO ejecutado.ipynb
```

Este notebook contiene los ejercicios resueltos y comprobados con `print()` para poder ver claramente la salida de cada apartado.

## Contenido trabajado

En los ejercicios se trabajan conceptos básicos e intermedios de Python, como:

- Variables y tipos de datos.
- Cadenas de texto.
- Listas, tuplas, diccionarios y sets.
- Condicionales.
- Bucles.
- Funciones.
- Funciones lambda.
- Uso de `map()`, `filter()` y `reduce()`.
- Manejo de excepciones.
- Programación orientada a objetos con clases.

## Cómo abrir el proyecto

Para abrir el proyecto se puede utilizar **Visual Studio Code** con la extensión de Jupyter instalada.

Pasos recomendados:

1. Abrir Visual Studio Code.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `.ipynb`.
4. Ejecutar las celdas una a una para comprobar los resultados.

## Requisitos

Para ejecutar el notebook es necesario tener instalado:

- Python 3.
- Visual Studio Code.
- Extensión de Jupyter para Visual Studio Code.

También se puede ejecutar desde Jupyter Notebook o JupyterLab.
