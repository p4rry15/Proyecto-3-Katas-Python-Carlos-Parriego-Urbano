# Proyecto 3: Katas Python - Carlos Parriego Urbano

## Descripción

Este proyecto contiene la resolución de las katas de Python correspondientes al Proyecto 3.

El trabajo está realizado en formato **Jupyter Notebook**, lo que permite ejecutar cada ejercicio por separado y comprobar sus resultados de forma clara.

## Archivo del proyecto

```text
Proyecto 3: Katas Python - Carlos Parriego Urbano.ipynb
```

## Contenido

En el notebook se incluyen los ejercicios con su enunciado y su correspondiente solución en Python.

Los contenidos trabajados son:

- Variables y tipos de datos.
- Cadenas de texto.
- Listas, tuplas, diccionarios y sets.
- Condicionales.
- Bucles.
- Funciones.
- Funciones lambda.
- Uso de `map()`, `filter()` y `reduce()`.
- Manejo de excepciones.
- Clases y objetos.

## Cómo ejecutar el proyecto

El proyecto se puede abrir y ejecutar en **Visual Studio Code** usando la extensión de Jupyter.

Pasos:

1. Abrir Visual Studio Code.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo del notebook.
4. Ejecutar las celdas una a una para comprobar los resultados.

## Requisitos

Para ejecutar el proyecto es necesario tener instalado:

- Python 3.
- Visual Studio Code.
- Extensión de Jupyter para Visual Studio Code.

También se puede ejecutar desde Jupyter Notebook o JupyterLab.

## Observaciones

Los ejercicios están organizados de forma individual para facilitar su lectura, ejecución y corrección.
